راهنمای مدیر سایت

مدیریت ساده محتوا با گوشی

این نسخه با میزبانی ایستا و رایگان GitHub Pages ساخته شده است. برای انتشار خبر و یادداشت، نیازی به نصب نرم‌افزار یا خرید افزونه ندارید؛ فایل محتوای سایت را از داخل GitHub ویرایش می‌کنید.

نکته مهم: این سایت پنل مدیریت خصوصی و پایگاه داده ندارد. تغییراتی که در GitHub ثبت می‌کنید پس از انتشار به همه بازدیدکنندگان نمایش داده می‌شود. اطلاعات ورود GitHub را محرمانه نگه دارید.

افزودن خبر یا یادداشت

  1. وارد حساب GitHub شوید و مخزن سایت خود را باز کنید.
  2. فایل مطالب-آقاسید.json را انتخاب کنید.
  3. روی آیکون مداد یا گزینه ویرایش بزنید.
  4. یک مطلب تازه به آرایه posts اضافه کنید؛ نمونه زیر را کپی و متن آن را جایگزین کنید.
  5. در پایان گزینه Commit changes را بزنید تا تغییرات ذخیره و برای انتشار ارسال شوند.
{
  "posts": [
    {
      "title": "عنوان خبر یا یادداشت",
      "category": "اخبار",
      "date": "۱۴۰۵/۰۸/۲۵",
      "summary": "خلاصه کوتاه مطلب در این قسمت نوشته می‌شود.",
      "url": ""
    }
  ]
}

ویرایش بخش‌های ثابت سایت

برای تغییر عنوان‌ها، معرفی بخش‌ها، متن صفحه نخست یا اطلاعات مجموعه‌ها، فایل index.html را در GitHub باز و ویرایش کنید. برای تغییر رنگ‌ها و ظاهر، فایل style.css استفاده می‌شود.

تعویض تصویر پروفایل

تصویر جدید را با نام تصویر-آقاسید.svg در پوشه assets بارگذاری کنید و نسخه قبلی را جایگزین کنید. بهتر است تصویر افقی یا عمودی با کیفیت مناسب و حجم بهینه باشد.

انتشار تغییرات

پس از ثبت هر تغییر در مخزن، GitHub Pages معمولاً به‌صورت خودکار سایت را به‌روزرسانی می‌کند. ممکن است چند دقیقه طول بکشد. در صورت مشاهده نسخه قبلی، صفحه را دوباره بارگذاری کنید.
